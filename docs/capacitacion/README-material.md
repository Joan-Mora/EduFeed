## 💡 Recomendaciones

### Para Conversión a PowerPoint
Las presentaciones en Markdown pueden convertirse a PowerPoint usando:
1. **Pandoc** (CLI):
   ```bash
   pandoc presentacion-operadores-caja.md -o caja.pptx
   ```
2. **Marp** (para slides más estilizados)
3. **Reveal.js** (presentación web interactiva)

### Para Impresión
- Exportar evaluaciones a PDF antes de imprimir
- Usar papel A4, doble cara
- Incluir hojas de respuestas separadas para evaluadores

### Para Videos
- Usar OBS Studio para grabación de pantalla + narración
- Resolución: 1080p (Full HD)
- Formato: MP4 (H.264)
- Duración objetivo: 5-12 minutos por video
- Incluir subtítulos (accesibilidad)
